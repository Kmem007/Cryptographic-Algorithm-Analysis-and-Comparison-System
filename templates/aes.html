🔐 AES-128 Encryption — Step by Step
⚙️
Phase 1 — Setup
Input processing, key derivation & expansion
▼
1
Plaintext Input
Your message is received and converted into bytes (UTF-8 encoding).
2
Padding
Message padded to a multiple of 16 bytes using PKCS#7 — extra bytes are added so the block size fits exactly.
3
Plaintext → 4×4 State Matrix
The first 16 bytes are arranged into a 4×4 grid called the State Matrix. All AES operations happen on this matrix.
4
Key Derivation
Your secret key is hashed to produce a fixed 128-bit (16-byte) AES key.
5
Key Expansion → 11 Round Keys
The 128-bit key is expanded into 11 Round Keys (RK₀ to RK₁₀) using the AES Key Schedule. Each round uses a different key.
6
Initial AddRoundKey (RK₀)
State Matrix XOR'd byte-by-byte with Round Key 0. This is the initial whitening step — makes ciphertext unpredictable from the start.
↓
🔄
Phase 2 — Main Rounds (1 to 9)
Each round applies 4 transformations: SubBytes → ShiftRows → MixColumns → AddRoundKey
▼
{% for r in range(1,10) %}
Round {{ r }}
{% endfor %}
{% for r in range(1,10) %}
①
SubBytes
Every byte in the 4×4 matrix is replaced with a new value from the AES S-Box (a fixed 256-entry lookup table). Adds confusion — hides the relationship between key and ciphertext.
②
ShiftRows
Rows of the matrix are cyclically shifted left:
Row 0 → no shift  |  Row 1 → shift 1 left  |  Row 2 → shift 2 left  |  Row 3 → shift 3 left
Spreads bytes across different columns — adds diffusion.
③
MixColumns
Each column of 4 bytes is multiplied by a fixed matrix using Galois Field (GF 2⁸) arithmetic. Completely mixes bytes within each column — strongest diffusion step.
④
AddRoundKey (RK{{ r }})
State Matrix XOR'd with Round Key {{ r }}. Mixes secret key material into the state — ensures encryption depends on the key.
{% endfor %}
↓
🏁
Phase 3 — Final Round (Round 10)
Same as rounds 1–9 but MixColumns is skipped
▼
①
SubBytes
S-Box substitution applied to all 16 bytes of the State Matrix — same as previous rounds.
②
ShiftRows
Rows shifted left by 0, 1, 2, 3 positions — same as previous rounds.
③
⚠️ MixColumns — SKIPPED
MixColumns is intentionally omitted in the final round. This makes AES encryption and decryption symmetric in structure.
④
AddRoundKey (RK₁₀) — Final
State XOR'd with the last Round Key RK₁₀. This is the last transformation of the encryption process.
↓
✅
Phase 4 — Output
Final State Matrix → Ciphertext
▼
1
State Matrix → Bytes
The final 4×4 State Matrix is read column-by-column back into a sequence of 16 bytes.
2
CBC Chaining
In CBC mode, each encrypted block is XOR'd with the next plaintext block before encryption — preventing identical plaintext blocks from producing identical ciphertext.
3
✅ Base64 Encoded Ciphertext Ready
The raw cipher bytes are Base64 encoded for safe text transmission. Decryption reverses all steps using the same key.
