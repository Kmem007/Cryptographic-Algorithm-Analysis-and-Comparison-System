About the Project

Project Overview

This project is a web-based demonstration of fundamental cryptographic algorithms used in information security. The objective of this project is to help users understand how different cryptographic techniques protect data through encryption, decryption, and hashing.

The website provides both theoretical explanations and practical demonstrations of cryptographic algorithms, making it suitable for academic learning and experimentation.

Objectives of the Project

  • To understand the working of symmetric and asymmetric cryptographic algorithms.
  • To demonstrate encryption and decryption using AES and RSA.
  • To explain one-way hashing using SHA-256.
  • To compare cryptographic algorithms based on their characteristics.
  • To provide an interactive and educational learning platform.

Algorithms Used

AES (Advanced Encryption Standard)

~ AES is a symmetric key encryption algorithm used to secure sensitive data. It uses the same secret key for encryption and decryption and is known for its speed and high security.

RSA (Rivest-Shamir-Adleman)

~ RSA is an asymmetric encryption algorithm that uses a public key for encryption and a private key for decryption. It is widely used for secure key exchange and digital signatures.

SHA-256 (Secure Hash Algorithm)

~ SHA-256 is a cryptographic hash function that generates a fixed-length hash value from input data. It is irreversible and ensures data integrity.

Technology Stack

  • Backend: Python (Flask Framework)
  • Frontend: HTML, CSS
  • Cryptographic Libraries: Python Cryptography Libraries
  • Development Environment: VS Code

Educational Value

This project helps students visualize how cryptographic algorithms work in practice. By combining theory with live demonstrations, it bridges the gap between conceptual understanding and real-world implementation of information security techniques.
