Cryptographic Algorithm Demonstrations

This section demonstrates the working of cryptographic algorithms through interactive encryption, decryption, and hashing operations.

AES – Advanced Encryption Standard

AES is a symmetric key encryption algorithm that uses the same secret key for both encryption and decryption. It is widely used for securing sensitive data due to its speed and high security.

In this demonstration, plaintext is encrypted using a secret key and can be decrypted back to its original form.

Perform AES Encryption / Decryption

RSA – Rivest Shamir Adleman

RSA is an asymmetric encryption algorithm that uses a public key for encryption and a private key for decryption. It is commonly used for secure key exchange and digital signatures.

In this demonstration, data is encrypted using the public key and decrypted using the corresponding private key.

Perform RSA Encryption / Decryption

SHA-256 – Secure Hash Algorithm

SHA-256 is a cryptographic hash function that converts input data into a fixed-length hash value. It is a one-way function and cannot be reversed.

In this demonstration, the input message is hashed to generate a unique hash used for integrity verification.
