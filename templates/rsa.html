Key Generation — Step by Step
How RSA builds a public/private key pair from primes
▼
1
Choose Two Large Prime Numbers
Select two distinct large prime numbers p and q. These must be kept secret — they are the foundation of RSA security.
p = {{ keys.p if keys else '...' }}
q = {{ keys.q if keys else '...' }}
2
Compute Modulus n = p × q
n is the modulus used in both public and private keys. Its size determines the strength of RSA (512-bit here).
n = p × q = {{ keys.n if keys else '...' }}
3
Compute Euler's Totient φ(n) = (p−1)(q−1)
φ(n) counts integers less than n that are coprime to n. This is used to find the key exponents e and d.
φ(n) = (p−1) × (q−1)
4
Choose Public Exponent e
e = 65537 is the standard public exponent. It must satisfy gcd(e, φ(n)) = 1 (coprime with φ(n)).
e = 65537 | gcd(e, φ(n)) = 1 ✅
5
Compute Private Exponent d = e⁻¹ mod φ(n)
d is the modular inverse of e. It is mathematically impossible to derive d from e and n without knowing p and q — this is RSA's security guarantee.
d = e⁻¹ mod φ(n)
6
✅ Keys Ready
Public Key = (e, n) — share this with anyone.
Private Key = (d, n) — keep this secret always.
Public Key = (e={{ keys.e if keys else '...' }}, n)
Private Key = (d, n) — kept secret 🔒

Encryption — Step by Step
How the Public Key converts plaintext to ciphertext
▼
1
Plaintext → Bytes
Message converted to bytes using UTF-8 encoding. Split into chunks smaller than the key size.
2
Convert to Integer M
Each chunk of bytes is read as a large integer M. RSA performs math on integers, not text.
3
Apply RSA Encryption Formula
Each integer M is encrypted using the Public Key (e, n). The result C is the ciphertext integer.
C = Me mod n
4
✅ Ciphertext Encoded (Base64)
Encrypted integers encoded to Base64 for safe text display. Without the private key d, decryption is computationally infeasible.

Decryption — Step by Step
How the Private Key recovers the original message
▼
1
Ciphertext → Integers
Base64 ciphertext is decoded back into the encrypted integers C that were produced during encryption.
2
Apply RSA Decryption Formula
Each integer C is decrypted using the Private Key (d, n). This works because of the mathematical relationship between e and d.
M = Cd mod n
3
Why No Key Input Needed?
The Private Key (d, n) was generated in Step 1 and is stored in the server session. RSA's private key is never typed by the user — it is always stored securely.
Private Key auto-used from session 🔐
4
✅ Original Message Recovered
Decrypted integers converted back to bytes and then to the original text string. Decryption is only possible with the correct private key.
